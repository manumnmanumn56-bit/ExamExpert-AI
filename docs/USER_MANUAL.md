## 2. Administrator (Office of COE) Operational Guide

### 2.1 Logging In
1. Navigate to `http://localhost:8000/`.
2. Select the **Admin** portal tab.
3. Enter registered email (`admin@sjbit.edu.in`) and password (`Admin@SJBIT2026!`).
4. Click **Sign In to Examination Portal**.

### 2.2 Initiating a Question-Paper Faculty Allocation
1. Navigate to the **🎯 Allocation** tab.
2. Complete the cascading parameter selection in order:
   - **Academic Year**: Choose active examination cycle (e.g., `2025-26`).
   - **Department**: Select academic department (e.g., `MCA`).
   - **Syllabus Scheme**: Select curricular scheme (e.g., `2025`).
   - **Semester**: Select semester (`I`, `II`, `III`, or `IV`). Note that the system strictly prohibits Semesters V–VIII for MCA.
   - **Course / Subject**: Choose from syllabus-verified offerings (e.g., `25MCAI101 — Programming in Python`).
   - **Examination Type**: Regular, Make-up, Fast-Track, or Supplementary.
   - **Allocation Mode**:
     - *Balanced (50:50)*: Evenly distributes between internal SJBIT faculty and vetted external examiners.
     - *Internal Only*: Restricts candidates strictly to internal SJBIT faculty roster.
     - *External Only*: Restricts candidates strictly to external affiliated colleges.
   - **Number Required**: Set required question-paper setters (default: `2`).
3. Click **⚡ Run Deterministic Faculty Matching**.
4. Review the candidate cards generated by the 9-level deterministic matching engine.
5. Review the **Workload Balance Matrix** showing committed, reserved, and available capacities.
6. Click **📤 Submit Allocation to HOD for Approval**.
   - This records `RESERVED` ledger entries for candidate setters.
   - Dispatches an automated in-app notification to the departmental HOD.

### 2.3 Managing Institutional Users & Account Lockouts
1. Navigate to the **👥 Users** tab.
2. View user accounts, current login statuses, and failed attempt counters.
3. If a user is locked due to 5 consecutive failed attempts:
   - Click the **🔓 Unlock User** button next to their name.
   - An immutable entry is written to the audit log.
4. To provision a new user, click **+ Register New Institutional User** and fill in official credentials.

### 2.4 Managing Expertise Mappings
1. Navigate to the **🧬 Expertise Mappings** tab.
2. Review suggestions classified into:
   - `EXACT_EXPERIENCE`: Verified prior teaching experience of this specific course.
   - `SPECIALIZATION`: Faculty specialization keyword matching course title.
   - `RELATED`: Curriculum domain alignment generated on request.
3. To confirm a suggestion, click **Confirm**.
4. To generate on-demand domain mappings for a newly introduced subject, click **Generate Related Mappings** on the subject card.

### 2.5 Running Automated Acceptance Test Suites
1. Navigate to the **🧪 Test Suites** tab.
2. Review registered test suites (Modules 1–15).
3. To run an individual test suite, click **▶ Run** next to the module.
4. To run all suites end-to-end, click **▶ Run All Acceptance Suites**.
5. Real-time test results, execution durations, and full console outputs render dynamically. All tests run safely on isolated temporary databases with zero risk to production data.

## 3. Head of Department (HOD) Operational Guide

### 3.1 Logging In
1. Navigate to `http://localhost:8000/`.
2. Select the **HOD** portal tab.
3. Enter registered departmental credentials (e.g., `hod.mca@sjbit.edu.in` / `Hod@2026!`).

### 3.2 Reviewing Departmental Allocation Requests
1. Navigate to the **⏳ Pending Approvals** tab.
2. All allocation requests submitted by the COE Office for your department are listed with:
   - Subject code and course title.
   - Curricular scheme and semester.
   - Recommended internal and external faculty setters.
   - Matching provenance reasons and current workload levels.

### 3.3 Approving an Allocation Request
1. Review candidate appointments.
2. If satisfied, click **✓ Approve Allocation**.
3. Confirm approval in the prompt.
4. The system automatically:
   - Updates allocation status to `Confirmed`.
   - Converts `RESERVED` workload ledger entries to `COMMITTED`.
   - Sends notification alerts to the COE Admin and appointed faculty.

### 3.4 Replacing a Recommended Setter
1. If an appointed faculty member is unavailable or has a conflict:
   - Click **Replace Setter** on the candidate's card.
   - Select an alternative eligible candidate from the dropdown list.
   - Provide documented justification for the replacement.
   - Click **Confirm Replacement**.
   - The original candidate's workload reserve is released and transferred to the replacement.

### 3.5 Rejecting an Allocation Request
1. If the entire recommendation requires revision:
   - Click **✕ Reject Allocation**.
   - Enter a **mandatory detailed rejection reason** (rejections without documented reasons are strictly rejected by the server).
   - Click **Submit Rejection**.
   - The status transitions to `Rejected`, all reserved workloads are released immediately back to the pool, and the COE Admin is notified.

## 4. Faculty Member Operational Guide

### 4.1 Logging In
1. Navigate to `http://localhost:8000/`.
2. Select the **Faculty** portal tab.
3. Enter registered email (e.g., `faculty.mca@sjbit.edu.in`) and password (`Faculty@2026!`).

### 4.2 Viewing Question-Paper Setting Appointments
1. Navigate to the **📬 Notifications** tab.
2. Review real-time alerts regarding official nominations (`FACULTY_ASSIGNED`).
3. Click on a notification to mark it as read and view appointment details.

### 4.3 Downloading Official Appointment Orders
1. Navigate to the **📜 Order Archive** tab.
2. View your active question-paper setting orders.
3. Click **📄 Download PDF Order** to download the official appointment document bearing the COE digital reference number and examination parameters.

### 4.4 Profile & Workload Inspection
1. Navigate to the **👨‍🏫 Faculty** tab.
2. Review your personal profile:
   - Official institutional designation and department.
   - Registered total experience and verified courses taught.
   - Current active examination workload (committed papers for the active academic cycle).
